# 🧠 Domi’s Psychology

A Year 13 revision companion for **Cambridge International A Level Psychology (9990)**, covering the specialist options for Papers 3 and 4. It follows the official syllabus for 2027.

## What’s inside
- **All 4 specialist options**: Clinical, Consumer, Health and Organisational. That’s 20 topics and 60 subtopics, with simple notes, “in short” summaries, strengths and weaknesses, and the issues & debates for each topic.
- **All 20 key studies**, each in the same format: context, aim, sample, procedure, results, conclusion, evaluation, and issues & debates.
- **138 short YouTube videos**, each about one subtopic.
- **Quizzes** (132 questions with explanations), **flashcards** with spaced repetition (300+ cards), and **exam-style questions** with answer guides.
- **Listen**: notes are read aloud using the device’s built-in voices.
- **Notebook**: notes tagged by topic, with search, pins and colours, plus export/import.
- **Revision planner**, **exam guide** (papers, command words, essay and planning help) and a **debates & methods** toolkit.
- Works offline, has dark mode, adjustable text size and reading spacing, and works on phone and desktop.

All progress and notes are stored privately in the browser (localStorage). Use *Settings → Download full backup* to move them between devices.

No build step is needed: it’s plain HTML, CSS and JS. Content lives in `assets/content-*.js`.
